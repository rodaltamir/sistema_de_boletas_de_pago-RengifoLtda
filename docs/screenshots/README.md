# 📸 Guía para Guardar Capturas de Pantalla (Screenshots)

Coloca en esta carpeta las capturas de pantalla de la aplicación para que se visualicen automáticamente en el `README.md` principal del repositorio.

### Nombres de Archivo Recomendados:

| Archivo | Módulo / Pantalla Representada |
| :--- | :--- |
| `dashboard.png` | Panel de Control / Inicio (`/inicio`) con métricas generales |
| `empresas.png` | Selector y Gestión de Empresas Multi-Tenant (`/seleccionar-empresa`) |
| `empleados.png` | Módulo de Gestión de Empleados y Padrón Laboral (`/empleados`) |
| `planillas_sueldos.png` | Planilla de Sueldos y Salarios con Ley Laboral Boliviana (`/planillas`) |
| `planillas_patronal.png` | Planilla Patronal y Provisiones Sociales (`/planillas` - Pestaña Patronal) |
| `planillas_aguinaldos.png` | Planilla de Aguinaldos de Navidad y Duodécimas (`/planillas` - Pestaña Aguinaldos) |
| `boletas_pago.png` | Emisión y Vista Oficial de Boletas de Pago (`/boletas`) |
| `asientos_contables.png` | Generador de Asientos Contables y Comprobantes de Pago (`/asientos`) |
| `prefiniquitos.png` | Módulo de Prefiniquitos, Finiquitos y Beneficios Sociales (`/prefiniquitos`) |

### Recomendaciones:
* **Formato:** `.png` o `.jpg` (preferentemente `.png` con buena resolución).
* **Resolución sugerida:** 1920x1080 o similar para una visualización nítida.
